## Gaps corrected

- Adding GitHub no longer silently adds Development. Disabled modules cannot
  be duplicated; module removal is available in local settings.
- GitHub-only observation does not demand a runtime, push permission or
  Development commands, and does not advertise agent execution.
- Public activation and both resume paths require fresh preflight. A pause
  invalidates an in-flight activation; an already-approved scoped trial can
  resume without creating another admission.
- Structural edits remain forbidden while a paused project has pending work.
  Removing a fixed module prunes only its exclusive slots and bindings, keeps
  shared bindings/history, and normalizes the saved Swift draft before re-save.
- Runtime environment fields no longer leak into graph rail bindings that
  violate the existing strict OpenAPI contract and prevent Swift decoding.
- The canvas presents real inter-module routes, directional arrows and French
  labels. Internal/self and unconnected events remain under technical details.
  Generic module/slot editors are not exposed for fixed compositions.
- Harness consumer-only fixtures now explicitly seed a structurally validated
  snapshot; public activation/preflight tests exercise real provider boundaries.
